## Quick Reference: Existing Patterns to Follow

### Context Pattern
```rust
pub struct ProductContext<'a> {
    pub client: ApiClient,
    pub renderer: &'a OutputRenderer,
}
```

### Command Pattern
```rust
#[derive(Args, Debug, Clone)]
pub struct ProductArgs {
    #[command(subcommand)]
    command: ProductCommands,
}

pub async fn execute(args: ProductArgs, ctx: ProductContext<'_>) -> Result<()> {
    match args.command {
        ProductCommands::Resource { command } => match command {
            ResourceCommands::List { limit } => list_resources(&ctx, limit).await,
            // ...
        }
    }
}
```

### API Response Pattern
```rust
#[derive(Deserialize)]
struct ApiResponse {
    values: Vec<Item>,
}

let response: ApiResponse = ctx.client.get(&path).await.context("Failed to fetch")?;
```

### Output Pattern
```rust
#[derive(Serialize)]
struct Row<'a> {
    id: &'a str,
    name: &'a str,
}

let rows: Vec<Row<'_>> = items.iter().map(|i| Row { ... }).collect();
ctx.renderer.render(&rows)
```
