atlassian-cli Documentation

Command reference for Jira, Confluence, Bitbucket, and Jira Service Management (JSM). Authentication, profiles, and output formats.

Guides

Authentication & Profiles

Log in with API tokens, set up profiles for multiple instances, use bearer tokens for Bitbucket, and store credentials securely with AES-256-GCM encryption.

Command Reference

Every Jira, Confluence, Bitbucket, and JSM command with flags, examples, and sample output. Bulk operations, dry-run, and CI/CD patterns.

Install

Install via Homebrew, Cargo, or a prebuilt binary. macOS, Linux, and Windows supported. Verify, configure, and run your first command.

Changelog

Features, fixes, and version history by release, from the latest 0.4 line back through earlier versions.
