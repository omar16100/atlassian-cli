# Release v0.13.0

## Verification

The tests cover comment add, update and delete with query markers and percent
escapes. Invalid keys and IDs cause zero requests. Comment updates preserve role
and group visibility, including its identifier.

Transition tests cover duplicate names, Unicode collisions, reversed response
order, explicit IDs and partial failures. Bulk tests cover zero writes during
previews, confirmation refusal, empty labels and partial-delete failures.

Pagination tests cover more than 250 results, total limits, blank cursors,
continuation links, `/wiki` normalization, foreign origins and request budget
exhaustion. An empty page with a cursor produces an incomplete-result warning.
Credential tests cover the known key and old AES-GCM ciphertext.

Required checks: `TERM=xterm make pre-commit`, the exact CI format, strict Clippy
and complete workspace test commands, `cargo audit`, and all four `cargo deny`
checks. The local `dist plan --output-format=json` and the release-plan CI job
must pass. Linux and macOS CI must pass for the final head. The PR description
records the tested commit and CI links.

## Release procedure

1. Confirm version 0.13.0 in all six crates and the five internal dependency pins.
2. Run `cargo check --workspace` and `TERM=xterm make pre-commit`.
3. Run `dist plan --output-format=json`.
4. Confirm that `announcement_github_body` contains the 0.13.0 change notes.
5. Merge the release PR after all required CI checks pass.
6. Create the annotated `v0.13.0` tag on the merge commit.
7. Push the tag to start the release and crates.io workflows.
8. Verify the GitHub Release notes, all four platform archives and the macOS binary.
9. Verify all six crates on crates.io and the Homebrew formula.

The integration commit `5f54e18` passed Linux, macOS, format, Clippy and security
CI. Its local suite passed 1,177 tests and ignored one test. The release PR
records the final verification results and workflow links.
