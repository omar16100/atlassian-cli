# Release 0.11.0 (plan)

Status: shipped in v0.11.0 (PR #168), tag `v0.11.0` on `ca97cc3`.

## Context

`## [Unreleased]` in `CHANGELOG.md` held the entries from the 16 Oct 2026 dependency
work: PR #160 (rustls 0.23.46), #162, #164, #165, #166 and #167 (the five PRs of
[16102026_dependency_cuts_plan.md](16102026_dependency_cuts_plan.md)). The owner asked for a
release once #167 merged.

## Version choice: 0.11.0

Commands, output formats and the TLS backend are unchanged; retry delays come from a new
generator with the same policy and nanosecond-level arithmetic differences. The published
library crate `atlassian-cli-api` gains public items (`RetryConfig::delays()`, `RetryDelays`,
the `query` module with `encode_query_component`) and deprecates `RetryConfig::backoff()`.
Cargo would allow these additions in a patch release (`~0.10` accepts 0.10.1). The minor bump
is a project choice: a separate release boundary for a dependency sweep that changed the TLS
build, the YAML crate and the retry generator, in line with the project's pre-1.0 practice of
bumping the minor for deliberate changes (0.6.0, 0.9.0, 0.10.0). The `#[deprecated(since)]` attribute on
`backoff()` was changed from the provisional `0.10.1` to `0.11.0` in this release.

## Approach

Following `AGENTS.md` "Releasing":

1. `CHANGELOG.md`: Unreleased promoted to `## [0.11.0] - 2026-10-16` with a short paragraph,
   an empty `## [Unreleased]` above it, compare links for `[Unreleased]` and `[0.11.0]`.
2. `[workspace.package] version` in `Cargo.toml` and the five internal pins in
   `crates/cli/Cargo.toml` to 0.11.0.
3. `cargo check --workspace` to move `Cargo.lock`.
4. `make pre-commit` (`crates/cli/tests/cli_integration.rs` asserts the version).
5. `dist plan --output-format=json`: `announcement_tag` is `v0.11.0` and
   `announcement_github_body` contains the 0.11.0 section.
6. Codex review of the diff, pull request, CI green, squash merge.
7. Tag the merge commit on `main`: `git tag -a v0.11.0 -m "Release 0.11.0"`, push the tag.
8. Verify: `gh release view v0.11.0` shows the changelog section, four artifacts exist,
   the six crates are on crates.io at 0.11.0, the Homebrew formula was updated.
